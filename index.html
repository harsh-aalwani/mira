14 / DIRECTORY SYSTEM STACK

BUILT TO EVOLVE.

MIRA is built with modern, battle-tested open standards. The documented technology stack unites performant local runtimes with specialized multimodal machine learning models.

GUI-01 // SHELL

Electron

Desktop cross-platform client architecture delivering responsive interaction on Windows, macOS, and Linux.

SRV-02 // CORE

FastAPI

High-throughput asynchronous local Python backend coordinating indexing, agent logic, and IPC endpoints.

VEC-03 // INDEX

FAISS

Facebook AI Similarity Search engine optimized for high-performance dense vector clustering and retrieval.

VEC-04 // STORE

ChromaDB

Developer-friendly open-source vector database supporting rich metadata filtering and document persistence.

LLM-05 // RUNTIME

Ollama

Local inference runtime facilitating privacy-first execution of open weight language models without cloud dependence.

VIS-06 // MULTIMODAL

OpenCLIP

Open-source Contrastive Language-Image Pretraining projecting images and text into a unified vector space.

VIS-07 // CAPTION

BLIP

Bootstrapping Language-Image Pretraining generating rich semantic descriptions of captured diagrams and screenshots.

AUD-08 // SPEECH

FasterWhisper

Accelerated local speech-to-text implementation using CTranslate2 for rapid transcription of audio and video tracks.

DAT-09 // RECORD

SQLite / JSON

Lightweight structured local databases storing conversational session histories, source indices, and configuration.
